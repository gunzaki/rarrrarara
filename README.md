# Bouquet

Static site, walang build step.

## Deploy sa Vercel
1. I-unzip ito, tapos i-push sa GitHub repo, o gamitin ang `vercel` CLI sa loob ng folder.
2. Sa Vercel: Add New > Project > i-import yung repo.
3. Framework Preset: **Other**. Iwan na blangko ang Build Command at Output Directory.
4. Deploy.

Pwede ring i-drag and drop yung folder sa vercel.com/new.
